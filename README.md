# Dashboard Corinthians — Temporada 2025

## Sobre o projeto

Durante os estudos de dados e Power BI, surgiu a ideia de unir duas paixões: futebol e análise de dados. Este projeto reúne um dashboard interativo sobre a temporada completa de 2025 do Sport Club Corinthians Paulista.

## Objetivo

Transformar os dados da temporada em uma visão clara e visual, facilitando a análise do desempenho do Corinthians ao longo do ano.

## O que o dashboard apresenta

- Estatísticas das partidas da temporada;
- Desempenho geral da equipe;
- Indicadores individuais dos jogadores;
- Comparativos e análises por jogo;
- Conquistas do Corinthians na temporada de 2025.

## Ferramentas utilizadas

- Power BI
- Análise de dados

## Arquivo do projeto

O dashboard está disponível no arquivo `dashboard-corinthians.pbix`.
